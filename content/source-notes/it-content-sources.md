# IT Content Source Notes

This project treats Wikipedia, Wikidata, Britannica, project documentation, and canonical papers as discovery and source metadata, not as text to copy.

## Current first batch

- `ai-ml`: Dartmouth workshop, AlexNet, transformer paper, ChatGPT.
- `software-os`: Unix, Linux, Docker, Kubernetes.

## Editorial rules

- Prefer high-consensus milestones that are commonly used in teaching histories.
- Use Wikipedia/Wikidata for dates, aliases, and cross-checking.
- Write summaries and modal explanations in original curated prose.
- Keep events tied to a primary track and phase so Time Slice does not repeat the same event everywhere.
